# 日次 Git ダイジェスト & ワークスペース確認

リポジトリおよびワークスペースの現状を確認し、本日の作業サマリを作成してください。

## 実行内容
1. `git status` を確認し、未コミットの変更や新規作成ファイルがないか点検してください。
2. 直近24時間のコミット履歴（`git log -n 5 --oneline` 等）を確認し、直近の変更点を確認してください。
3. リモートリポジトリとの差分（`git fetch` 後、未プッシュ／未マージの差分）を確認してください。
4. 本日の開発者がスムーズに作業に入れるよう、現状のステータスと推奨アクションを簡潔にまとめて出力してください。

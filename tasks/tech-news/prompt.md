# AI活用 開発フロー自動化・効率化トレンド デイリーリサーチ

## 【目的】
AIを活用した開発フローの自動化・効率化（AIコーディングエージェント、パイプライン自動化、CI/CD・Hook連携、ハーネス設計、コードレビュー自動化、テスト自動生成等）に関する国内外の重要トレンドや実践事例を調査・抽出し、**認知負荷の低いシンプルな箇条書きレポート**を作成して届けてください。

## 【厳格な作成ルール】
1. **短くシンプルな箇条書き（認知負荷の低減）**:
   - 長文の段落テキストは禁止。
   - 各トピックは「**要点**」「**技術ポイント**」をそれぞれ **1行〜2行の短い箇条書き** で要約してください。
   - スマホや Slack でサッと流し読みできる簡潔さを最優先してください。
2. **必ず個別記事のパーマリンクを記載すること（グループ・一覧URLは禁止）**:
   - 参照元 URL は、**必ずその記事そのものの個別パーマリンク**（例: `https://zenn.dev/<user>/articles/<id>`、`https://qiita.com/<user>/items/<id>`、GitHub リポジトリのURL）を記載してください。
   - **トピック一覧・グループ一覧（例: `https://zenn.dev/topics/...`）やサイトのトップページ（例: `https://qiita.com/`）の記載は禁止**です。
   - 検索結果に実際に存在する個別記事のURLを特定・確認してそのまま記載してください（推測でのURL生成は厳禁）。
3. **リンク行の独立（Slack レンダリング対応）**:
   - Slack のパーサー仕様に合わせて、見出し `###` に直接リンクを埋め込まず、タイトル下の独立した行に `🔗 参照元: [記事名/サイト名](個別URL)` として記述してください。
4. **ファイル保存**:
   - 作成したレポート全文をリポジトリ内の `tasks/tech-news/report.md` に保存してください。

## 【実行手順】
1. **国内ソースの調査**: はてなブックマーク（テクノロジー）、Zenn、Qiita、各社テックブログ等から、直近注目されている開発自動化・エージェント実践記事を5件収集。
2. **海外ソースの調査**: Hacker News、GitHub Trending、DEV.to 等から、AIツール、エージェントパイプライン、CI/CD統合の最新動向・議論を5件収集。
3. **日本語箇条書き要約**: 国内5件・海外5件（計10件程度）を選定し、短い箇条書きで整理。
4. **個別URLの確認**: 各トピックのリンクが個別記事のパーマリンクであることを確認。
5. **成果物保存**: `tasks/tech-news/report.md` に書き込み。

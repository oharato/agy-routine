# AI活用 開発フロー自動化・効率化トレンド デイリーリサーチ

## 【目的】
AIを活用した開発フローの自動化・効率化（AIコーディングエージェント、開発パイプラインの自動化、CI/CD・Hook連携、ハーネス設計、コードレビュー自動化、テスト自動生成など）に関する国内外の重要トレンドや実践記事（はてなブックマークIT、Zenn、Qiita、Hacker News、GitHub Trendingなど）を重点的に調査・抽出し、国内5件・海外5件（計10件程度）のサマリーレポート（海外トピックは日本語に翻訳・要約）を作成して届けてください。

## 【実行手順】
1. **国内ソースの調査**:
   - 国内の主要情報ソース（はてなブックマーク テクノロジー、Zenn、Qiita のトレンド等）から、直近で注目されている「AIを使った開発フローの自動化・効率化・自律化」に関する記事や企業テックブログの実践事例を優先的に検索・収集してください。
2. **海外ソースの調査**:
   - 海外の主要情報ソース（Hacker News、GitHub Trending、DEV.to、daily.dev等）から、AIコーディングツール、エージェントパイプライン、CI/CD統合、開発者向けAIツールに関する最新動向・議論を検索・収集してください。
3. **厳選・日本語要約**:
   - 海外記事や議論の内容をわかりやすい日本語に翻訳・要約し、実務における開発自動化・効率化として再現性や示唆に富む重要トピックを国内から5件程度、海外から5件程度（計10件前後）厳選してください。
4. **構造化レポートの作成 & ファイル保存**:
   - 各トピックについて「タイトル」「概要・要点」「技術的な注目ポイント」「参照元リンク」を整理した構造化レポートを作成してください。
   - **重要**: Slack 自動送信連携のため、作成したレポート全文をリポジトリ内の `tasks/tech-news/report.md` にファイル書き込み（上書き保存）してください。

## 【成果物フォーマット】
以下の構成で Markdown レポートを作成・保存してください：

```markdown
# 🚀 Web開発・AI自動化トレンド要約 (YYYY-MM-DD)

## 🇯🇵 国内トレンド (5件)
### 1. [タイトル](URL)
- **概要・要点**: ...
- **技術的注目ポイント**: ...

...

## 🌐 海外トレンド (5件・日本語要約)
### 1. [タイトル / 原題](URL)
- **概要・要点**: ...
- **技術的注目ポイント**: ...

...

## 💡 本日の総括と実務への示唆
- 本日のトレンド全体から見られる動向や、実務開発への適用アイデアを2〜3点にまとめてください。
```
